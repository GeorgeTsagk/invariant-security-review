# Agent passes

Create one file per agent interaction using `<UTC-date>-<agent-name>-<unique-id>.md`. Create it before target analysis and never reuse its pass ID.

A pass records agent identity, source and catalog baselines, objective, selected scope, prior work discovered, invariants read or written, code paths reviewed, experiments, outputs, gaps, and handoff. Update it at phase boundaries and before stopping. Preserve incomplete and no-finding passes.

Use [the pass template](../templates/PASS.md). Keep the matching row in [the overview](../REVIEW_LOG.md) synchronized.
